### Break Through Tech AI Studio | Google

**Project: [FaithfulMed — A Multi-Agent System for Faithful, Patient-Friendly Medical Explanations](https://github.com/Break-Through-Tech/Google-2E-faithfulmed-a-multi-agent-system-for-faithful-patient-friendly-medical-explanations)**

As a Break Through Tech AI Fellow, I collaborated on FaithfulMed, a multi-agent AI system designed to generate accurate, accessible, and patient-friendly medical explanations.

**My Key Contributions:**
- **Data Exploration:** Explored and analyzed project datasets to understand their structure, characteristics, and suitability for the system.
- **Verifier Agent Development:** Developed a verifier agent to assess the faithfulness of generated medical explanations.
- **Baseline Pipeline:** Built a baseline pipeline to establish a reference point for comparing the performance of the multi-agent system.
- **Ablation Study:** Developed and evaluated a version of the pipeline without the verifier agent to investigate the verifier's contribution to overall system performance.
